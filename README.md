# Communa8 Tasks

Communa8 Tasks is a Nextcloud-first task application for the Communa8 platform.

The goal of this fork is a focused experience built around direct CalDAV synchronization with Communa8's Nextcloud server, including private task lists and lists shared between Nextcloud users. The application is being simplified so Communa8 members do not need DAVx⁵, Google Tasks, Microsoft To Do, or another synchronization service.

## Status

Early development fork. Android is the first target.

Planned Communa8 integration includes:

- direct CalDAV synchronization with `app.communa8.org`
- Nextcloud-compatible task lists and VTODO data
- shared Nextcloud task lists and read/write permissions
- local/offline task access and background synchronization
- Communa8 branding and streamlined sign-in
- reminders, recurring tasks, subtasks, priorities, filters, and widgets retained where practical
